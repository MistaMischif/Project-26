# Living Table 0.6.3 — Themed rewards

Special cards release twelve character-themed 3D items: purple berries, striped candy canes, gumdrops, peanuts, lollipops, or snowflakes. They circle the lifted illustration twice, then float to the correct destination square. Four small matching scenery clusters sprout around that square and disappear after the celebration.

The card still reaches the discard pile in two seconds. Pawn movement waits for the themed items to arrive; player pieces retain their starting size. Chess remains available.

In the headset, choose Candy Land → TEST SPECIAL CARDS. Use REPLAY SPECIAL or NEXT SPECIAL to inspect all six celebrations. This test mode does not change saved games.
