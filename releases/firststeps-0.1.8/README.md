# First Steps 0.1.8 - attached board handles

Grab both gold side grips to move and rotate the board. Pinch any corner knob and pull outward/inward to resize the board around its center. The held grip becomes larger and luminous cyan; the complete board grid pulses while adjusting. Gameplay is suspended until release, with the same session, move history and pending action retained.

Physical-board adjustments require ACCEPT BOARD afterward. Piece-size scanning and physical reconciliation remain separate. ALIGN BOARD still starts automatic camera fitting; manual geometry adjustment uses the attached handles. RECENTER remains an accessibility/recovery action for placing the board again.

Limits: real-headset handle feel, visibility and performance need founder acceptance. Camera fitting/sizing remains subject to the 0.1.7 real-board limitations. No new inference host or service restart is required for these UI changes.
