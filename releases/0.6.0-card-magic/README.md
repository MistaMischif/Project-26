# Living Table 0.6.0 — card magic

Candy Land special characters now appear as flat card illustrations. They remain attached throughout the two-second reveal and flight, then dissolve into themed sparkles after reaching the discard pile. Sparkles burst behind the illustration. The named physical card remains in the stack.

Removed runtime character sculptures, character interactions and voices, character movement charms, board celebrations, and the treat bowl. Original models and voice clips are retained outside Resources in ArchivedCharacterAssets. Player pieces, movement feedback, music, separate game host, chess, and session rules remain available.

Validation: Candy rules, vision fixtures, and card-magic scene test passed. Scene test checks no character actors/bowl, player pieces, rigid card attachment, no dissolve during flight, two-second presentation, particle cleanup and retained discard.

Headset visual appearance and comfort still require user review. Camera fixture tests do not establish real-board tracking accuracy.
