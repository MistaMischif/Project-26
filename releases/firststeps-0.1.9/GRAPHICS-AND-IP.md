# Visual provenance and patent status

The First Steps release renders its chess pieces with ChessPieceModel, board/back panel with TableCabinetVisual and TableCabinet shader, square buttons with TableButtonVisual and GlossButton, corner knobs with Unity primitives, and grid/ghost overlays with project shaders. These are project-authored procedural visuals, not copied images of commercial board games. The build excludes Candy Land resources; packed asset paths are checked by FirstStepsRelease.Build and retained with release evidence.

Unity/Meta SDK content, font/runtime resources and open-source dependencies remain third-party licensed components, not COLTRAN-owned artwork. This record is a source/packaging audit, not a trademark clearance or ownership assertion over SDK assets.

The supplied patent packet remains an unfiled draft. No filing receipt or application number has been recorded. The home screen therefore says “Patent application in preparation.” It does not claim patent pending, registration, grant, exclusivity or guaranteed protection. Update that wording only against an actual filing receipt.
